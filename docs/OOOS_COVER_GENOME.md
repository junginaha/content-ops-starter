# ooOS 표지 게놈 (Cover Genome v1)

원고를 분석해 책마다 다른 표지를 만든다. 템플릿에 색만 바꿔 끼우는 방식이 아니다.

## 결정 방식
| 결정 | 근거 |
|---|---|
| 색 | 장르별 팔레트 3~4종 중 원고의 온도(1인칭·대화 비중)·무게(문단 길이·문어체)에 가까운 것. 비슷한 후보끼리는 원고 시드로 선택 |
| 구도 | 장르별 3종: 대표 구도 · 장별 분량을 그리는 구도 · 제목 첫 글자 구도. 장 분량 편차가 크면 분량 구도 우선 |
| 모티프 | 장 수 = 물결·고리·칸·언덕 수, 장 분량 = 띠·언덕·막대 크기 |
| 뒤표지 | 원고 문장 1개를 그대로 발췌(창작 없음) — 저자 승인 필요 경고 |
| 시드 | 제목+원고 FNV-1a 해시. 같은 원고 → 같은 표지, 다른 원고 → 다른 표지 |

구도 7종: 수평선 · 지형(언덕) · 동심원 · 리듬 띠 · 모듈 격자 · 정보 띠 · 한 점 · 첫 글자

## 인쇄 안전장치
- 모든 색 총잉크량 280% 이하(테스트로 강제), 투명도 없음, 바탕색은 도련 끝까지
- 10pt 미만 글자는 K100 또는 종이색 1도 — 4도 핀트 어긋남 방지
- 책등 6mm 미만이면 책등 색을 바꾸지 않음(제본 오차 노출 방지)
- 바코드는 흰 판 위 K100, 유색 바탕에서는 ISBN 표기·가격까지 흰 판 확장

## 수동 지정
`/os` 화면 또는 옵션 `coverLayout`, `coverPalette`. `coverGenome: false`면 기존 흑백 표지.

## 한계
- 사진·일러스트 생성 없음(벡터 도형과 활자만). 앞표지 이미지를 넣으면 그 이미지를 우선
- 화면 색과 인쇄 색은 다름 — 교정쇄 확인 필수
