## 공통 편집 원칙
1. 본문은 안정적인 폭·행간·정렬·여백을 우선하고 페이지마다 새 디자인을 만들지 않는다.
2. 짧은 글은 본문·인용·주석·출처·캡션·작가 소개·인덱스·이미지 인터루드 등 반복 모듈로 확장한다. 글자 확대나 무의미한 공백으로 분량을 부풀리지 않는다.
3. 페이지 리듬은 제한된 색상, 제목 단계, 5~7개 페이지 유형 등 소수의 규칙으로 만든다.
4. 이미지는 장식이 아니라 본문을 해석·확장·대조하는 역할로 배치하고 출처와 캡션을 관리한다.
5. 아카이브·다언어 출판은 원문·번역·해설·팩시밀리·출처를 별도 레이어로 관리한다.
6. 오픈 스파인·별색·다종 종이·접지·타공·디보싱은 자동조판 기본값이 아닌 제작 옵션으로 둔다.

## 권리·라이선스 기준
- **USE:** 실제 사용 범위와 라이선스가 확인된 자산에 한해 사용.
- **ADAPT:** 일반적 레이아웃 원칙·색상·그리드·정보 위계를 독자적으로 재구성.
- **CHECK:** 서체명·권리자·라이선스·사양·출처가 불명확하거나 용도 확인 필요.
- **SUBSTITUTE:** 권리·용도가 명확한 대체 자산 사용. 한글 대체 후보 Noto Sans/Serif CJK KR(SIL OFL 1.1).
- **CLEARED:** 해당 프로젝트·매체·기간·지역·수량에 대한 명시적 허락과 증빙을 확보한 경우에만 사용.
- **NO:** 허락 없는 원본 이미지·일러스트·본문·표지 파일의 복제·재배포·편집 원본 사용 금지.

공개 갤러리·JPG·PNG·PDF는 열람 또는 미리보기일 수 있으며 자유 재사용이나 편집 가능한 원본을 뜻하지 않는다. 서체는 인쇄·전자문서·서버·앱·웹·EPUB 권리를 각각 확인한다.

## 데이터 품질 점검 사항
1. `The House of Doctor Koolhaas`와 `The House of Dr Koolhaas`가 별도 레코드로 존재한다. 동일 출간물의 표기 변형인지 별개 판본인지 확인 후 병합 또는 구분한다.
2. `On the Edges of Graphic Design from A—Z—∞` 레코드의 publisher 필드가 비어 있다. 조사 기록의 Set Margins 표기를 근거로 원본 필드 보완 여부를 검토한다.
3. 일부 레코드는 판형·페이지 수·서체·직접 이미지 링크가 미기재다. 확인 전 추정하지 않고 CHECK로 유지한다.
4. GitHub main의 데이터 병합은 확인했으나 Vercel 운영 배포 상태는 별도 확인이 필요하다.

## 권장 ooOS 편집 파이프라인
1. 원고·이미지·출처·캡션·저자·권리자 정보를 수집한다.
2. 글 길이·유형·이미지 역할·인용·자료 출처를 구조화한다.
3. 12개 모듈 중 기본 모듈을 선택하고 페이지 유형을 5~7개로 제한한다.
4. 본문 스타일·그리드·여백·행간을 고정한 뒤 장 제목·인용·이미지·주석을 배치한다.
5. 이미지·본문·서체·번역·아카이브 자료별 권리 상태와 증빙을 확인한다.
6. 재단 여백·폰트 임베딩·해상도·색상 모드·페이지 순서·링크·캡션·목차를 프리플라이트한다.
7. 사람의 최종 승인 후 인쇄용 PDF·전자책 패키지를 생성하고 해시·버전·검수 결과를 보관한다.
