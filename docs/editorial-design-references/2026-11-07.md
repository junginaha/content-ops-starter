## 2. Hybrid: Curiosity in All Things

- **출판/편집/디자인:** Victionary, 2025. 편집·디자인 Hybrid Design.
- **공식 선정:** AIGA *50 Books | 50 Covers 2025* Winner, Book category. AIGA 공식 설명은 각 섹션을 에세이와 프로젝트 사례의 짝으로 구성하고, 고객사나 분야가 아니라 아이디어와 영향 관계에 따라 편집했다고 밝힌다.

## 3. 95 Ways to Step on the World

- **출판/저자:** Gabriel Krauze, Topsafe, 2026. 초판 400부 한정. AIGA 기록은 Gabriel Krauze를 publisher로 기재하고, Topsafe는 발행·유통 페이지를 운영한다.
- **디자인:** Zak Group. 북·표지 디자이너 Ladina Doerig, 크리에이티브 디렉터 Zak Kyes.
- **공식 선정:** AIGA *50 Books | 50 Covers 2025* **Cover Winner**. Book Winner가 아니라 표지 부문 수상이다. 다만 AIGA 설명에는 내부 조판도 검정고딕(blackletter) 중심의 type-rich layout으로 설계했다고 구체적으로 기록돼 있다.
- **공식 수상 페이지:** https://50books50covers.secure-platform.com/a/gallery/rounds/417/details/79145
- **실제 책 이미지 갤러리:** Le Grand Jeu 상품 페이지가 5개 상품 이미지를 표시하고, 확인한 이미지 3개는 실제 내지 펼침면(첫 장의 눈 이미지 reveal, 두 단 본문, 검정 바탕 흰 글자 페이지)을 보여준다. https://www.legrandj.eu/products/gabriel-krauze-95-ways-to-step-on-the-world
- **출판사·사양:** https://topsafe.co/products/95-ways-to-step-on-the-world-gabriel-krauze — 111×161mm, 80쪽, 문고판, Munken Print Cream 80gsm, 삽화 10점, ISBN 978-1-0369-7223-3. AIGA 공식 설명도 111×161mm·80쪽·80gsm을 확인한다.
- **직접 이미지·PDF:** 상품 갤러리의 내지 이미지는 열리지만 이번 확인에서 100×100 썸네일만 제공됐다. 전체 해상도 JPG/PNG, 공개 PDF, 편집 가능한 원본은 확인되지 않았다.
- **서체:** Carol Gothic (ParaType)와 HAL Timezone (HAL Typefaces) — 둘 다 **CHECK**. Carol Gothic은 Adobe Fonts에서 상업 디자인·PDF 사용을 허용한다고 안내하지만 MyFonts는 일반 데스크톱 출력과 전자문서 라이선스를 구분한다. ooOS 서버 자동 생성·편집 가능한 템플릿 사용은 별도 서면 확인이 필요하다. https://fonts.adobe.com/fonts/carol-gothic / https://www.myfonts.com/collections/carol-gothic-font-paratype. HAL Timezone 공식 파운드리는 서체 정보만 공개하며 자동 문서 생성·서버 라이선스는 확인되지 않았다. https://type.hanli.eu/timezone/
- **한글 대체:** Noto Sans CJK KR — **SUBSTITUTE/USE**, SIL OFL 1.1. 원본 블랙레터의 시각적 대체는 아니므로, 제목용 한글 디스플레이 서체는 별도 라이선스 검토가 필요하다.
- **색상·재료:** 코발트 블루 표지, 다이컷 눈 구멍, 첫 장의 하프톤 눈 이미지, 크림색 Munken 내지. 코발트·크림·검정 대비 원칙 **ADAPT**. 다이컷은 표지 구조와 후가공 비용을 별도 승인해야 한다.
- **조판·페이지 리듬:** 111×161mm의 작은 판형, 80쪽, 삽화 10점. 저자의 문신 레터링에서 영감을 받은 블랙레터 타이포그래피를 사용해 단편적·실험적 자전 서사의 어조를 시각화한다. 확인된 펼침면에는 두 단 본문과 검정 바탕 흰 글자 페이지가 나타난다. 정확한 본문 폭·행간·여백·그리드는 미공개.
- **ooOS 적용:** 짧고 파편적인 글을 작은 판형에 묶을 때 2~3개 타이포그래피 규칙을 반복하고, 검정 페이지나 이미지 reveal은 책 전체에서 소수만 사용한다. 미니멀 에세이의 기본 템플릿이 아니라 실험적 작가 에디션의 대비 사례로 활용한다.
- **권리:** 레이아웃 **ADAPT** / 색채 원칙 **ADAPT** / Carol Gothic·HAL Timezone **CHECK** / 한글 대체 본문 서체 **USE** / 원본 사진·본문·표지 그래픽 무허가 사용 **NO** / 편집 가능한 원본 **NO**.

## 오늘 라이브러리에 추가할 핵심 원칙

1. 짧은 글은 반복 가능한 인덱스 모듈과 상호참조로 확장한다. 문장을 늘리는 대신 항목 사이의 관계를 설계한다.
2. 긴 에세이집은 에세이와 이미지·프로젝트를 주제별로 짝지어 페이지 리듬을 만든다.
3. 실험적 타이포그래피와 특수 후가공은 선택 옵션으로 둔다. 원본 서체의 서버·상업 인쇄 라이선스와 제본 가능성을 먼저 확인한다.
