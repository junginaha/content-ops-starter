## 1. Prototyp 1928–33: Schule der Arbeit

- **출판/디자인:** Verbrecher Verlag, 2025. 저자·편집 Ute Richter. 디자인 Nelly Nakahara, Gerrit Brocks.
- **공식 선정:** Stiftung Buchkunst, *Die Schönsten Deutschen Bücher 2025*, Ratgeber–Sachbücher 부문. 심사평은 흑백 텍스트-이미지 구성, 오픈 스파인, 네온색 실 제본, 본문 펼침면의 ragged-right 정렬, 굵은 인용문을 제2의 읽기 층으로 분리한 점, 안쪽 제본선까지 넓게 확장한 조판 폭을 구체적으로 평가한다.
- **공식 평가/갤러리:** https://www.stiftung-buchkunst.de/die-schoensten-deutschen-buecher/die-praemierten/prototyp-1928-33/
- **출판사 페이지 및 공개 내지 미리보기:** https://www.verbrecherverlag.de/shop/projekt-1928-33/
- **공개 PDF 미리보기:** https://www.verbrecherverlag.de/wp-content/uploads/2024/11/Leseprobe-Richter-Projekt-1928-33.pdf — 실제 내지의 기록 사진, 문서, 건축 도면, 인용문을 포함한 일부 발췌본. 전체 책이 아니며 편집 가능한 원본이 아니다.
- **사양:** 165×216mm. Stiftung Buchkunst는 128쪽, 출판사 쇼핑 페이지는 120쪽으로 표기해 차이가 있다. 출판사 사양은 흑백 이미지 64점. ISBN 978-3-95732-617-1.
- **서체:** New Century Schoolbook (Linotype/Monotype), ABC Walter Alte (Dinamo). 둘 다 **CHECK**. New Century Schoolbook은 MyFonts의 Desktop/Company Desktop/Electronic Document 라이선스가 구분되며, 일반 데스크톱 라이선스로 서버 자동 조판을 가정할 수 없다. ABC Walter Alte는 Dinamo가 의뢰 고객별 라이선스와 공용 서버 금지를 명시한다. ooOS 서버 사용은 각 파운드리의 서면 확인 전 사용하지 않는다. 한글 대체: Noto Serif CJK KR + Noto Sans CJK KR, SIL OFL 1.1 **SUBSTITUTE/USE**.
- **색상:** 흑백 내지, 흰색 표지 소재, 네온 컬러 실 제본. 흑백과 단일 강조색 원칙 **ADAPT**. 실 제본과 오픈 스파인은 제본소 사전 확인.
- **조판:** ragged-right 본문 칼럼, 안쪽 제본선 가까이 확장된 넓은 조판 폭, 굵은 인용문을 별도 읽기 층으로 배치, 기록 사진·문서·도면에 출처 캡션을 붙인다. 정확한 행간·여백 수치는 미공개.
- **ooOS 적용:** 회고록·구술사·아카이브 에세이에서 본문 그리드는 안정적으로 유지하고, 인용문·기록물·출처 캡션을 별도 레이어로 관리한다.
- **권리:** 레이아웃/색상 **ADAPT**; 원본 서체 **CHECK**; 한글 대체 서체 **USE**; 원본 사진·문서·본문 무허가 재사용 **NO**; 편집 원본 **NO**.

## 2. Constructive Disobedience: An Experimental Methodology in Architecture

- **출판/디자인:** Birkhäuser, 2025. 편집 Matthias Ballestrem, Katharina Benjamin, Helga Blocksdorf. 디자인 hla.studio / Tobias Dahl, Patrick Martin.
- **공식 선정:** Stiftung Buchkunst, *Die Schönsten Deutschen Bücher 2025*, Fachbücher 부문. 심사평은 연한 분홍 섹션 페이지, 코팅/비코팅 종이 전환, 한 서체의 굵기·크기 변화, 펼침면을 가로지르는 큰 장 제목, 본문 내 참고문헌의 분홍 강조, 오픈 스파인의 펼침성을 구체적으로 평가한다.
- **공식 평가/실제 내지 이미지:** https://www.stiftung-buchkunst.de/die-schoensten-deutschen-buecher/die-praemierten/constructive-disobedience/
- **출판사 사양:** https://birkhauser.com/en/book/9783035628302
- **공개 PDF 미리보기:** https://api.pageplace.de/preview/DT0400.9783035628302_A50350626/preview-9783035628302_A50350626.pdf — 실제 본문과 이미지가 포함된 발췌 PDF. 전체 296쪽이 아니며 편집 가능한 원본이 아니다.
- **사양:** 230×300mm, 296쪽. 출판사 카탈로그는 흑백 이미지 96점, 컬러 이미지 104점, 단색 지도 54점을 표기한다. 인쇄본 ISBN 978-3-0356-2829-6, 전자책 ISBN 978-3-0356-2830-2.
- **서체:** Neue Haas Grotesk Text Medium/Bold (Commercial Type / Christian Schwartz), Total Text (hla.studio / Patrick Martin). 둘 다 **CHECK**. Commercial Type은 자동 문서 생성 서버 라이선스를 별도로 두고, AI 관련 조항의 적용 범위는 설명문에서 일부 좁혀져 있으므로 AI 보조 조판/PDF 생성이 허용되는지 서면 확인이 필요하다. Total Text의 공개 판매·라이선스 조건은 확인되지 않았다. 한글 대체: Noto Sans CJK KR, SIL OFL 1.1 **SUBSTITUTE/USE**.
- **색상:** 검정 표지와 연한 네온 핑크 섹션·참고 표시. 정확한 Pantone 번호는 미공개. 색상 원칙 **ADAPT**; 별색과 종이 전환은 인쇄소 승인 필요.
- **조판:** 1개 서체의 여러 굵기·크기, 대형 장 제목, 본문 속 참고문헌 강조, 텍스트·건축 도면·사진의 교차, 코팅/비코팅 종이 전환. 정확한 본문 폭·행간·그리드는 미공개.
- **ooOS 적용:** 문화예술 교양서에서 한글 본문 그리드를 안정적으로 유지하고, 장 제목과 참고 표시만 한 가지 강조색으로 통일한다. POD 기본값은 종이 전환 대신 디지털 색상 구분으로 구현한다.
- **권리:** 레이아웃/색상 **ADAPT**; 원본 서체 **CHECK**; 한글 대체 서체 **USE**; 원본 이미지·도면·본문 무허가 재사용 **NO**; 편집 원본 **NO**.

## 3. Posters with Purpose: In Conversation with 3 Poster Design Masters

- **출판/디자인:** Design Ethics and Visual Integrity Lab (DEVIL), Nanyang Technological University, 2025. 아트디렉션·리드 디자인 Lisa Winstanley, 디자인 Cammie Toh Su Qi.
- **공식 선정:** AIGA *50 Books | 50 Covers 2025* Winner. 디자이너 포트폴리오는 536개 출품작, 29개국 참여와 AIGA 컬렉션 수록을 명시한다.
- **수상 근거·실제 표지/내지 갤러리:** https://www.lisawinstanley.com/post/posters-with-purpose-wins-aiga-50-books-50-covers
- **실제 상품 이미지 갤러리:** https://draw-down.com/products/posters-with-purpose-in-conversation-with-3-poster-design-masters — 상품 페이지가 열리고 22개 이미지 항목을 표시한다.
- **사양:** 240×305mm. 디자이너 포트폴리오와 Draw Down 판매 페이지 모두 150쪽으로 표기한다.
- **서체:** 공개 프로젝트 크레딧에서 정확한 서체명 확인 불가 — **CHECK**. 한글 대체: Noto Sans CJK KR, SIL OFL 1.1 **SUBSTITUTE/USE**.
- **색상/제작:** 네온 오렌지와 보라색의 접이식 더스트 재킷, 흰색 천 표지, 블라인드 디보싱. 색상과 레이어 원칙 **ADAPT**. 접지·타공·디보싱은 별도 제작비와 후가공 가능성 확인.
- **조판:** 세 명의 인터뷰를 각기 다른 레이어로 구성하고, 일부 포스터를 접지·타공 삽입물로 분리한다. 한 챕터는 한국어/영어 병기. 본문 폭·행간·정확한 그리드·이미지 면적 비율은 미공개.
- **ooOS 적용:** 인터뷰집에서 기본 본문 그리드는 고정하고, 인터뷰이별 장 시작 페이지와 시각적 표식만 차별화한다. 접지·타공은 프리미엄 에디션에서만 옵션으로 제안한다.
- **권리:** 레이아웃/색상 **ADAPT**; 원본 서체 **CHECK**; 한글 대체 서체 **USE**; 원본 포스터·본문 무허가 재사용 **NO**; 편집 원본 **NO**.
- **자료 상태:** 실제 상품 이미지 갤러리와 디자이너 포트폴리오는 열람 확인. 직접 JPG/PNG 다운로드 및 편집 가능한 원본은 확인되지 않음.

## 오늘 라이브러리에 추가할 핵심 원칙

1. 본문은 안정적인 그리드로 유지하고, 인용문·자료·참고 표시를 별도 읽기 레이어로 분리한다.
2. 페이지 리듬은 색상 한 가지, 굵기 변화, 이미지 인터루드 등 소수의 규칙으로 만든다.
3. 오픈 스파인·접지·타공·별색은 자동 조판의 기본값이 아니라 인쇄소 검수 후 선택하는 제작 옵션으로 둔다.
