# ooOS 인쇄 출판 패키지 (Print Package v1)

`/os` → 출간 목표에 **종이책** 포함 → "종이책 인쇄 PDF 프리플라이트" 카드 → **인쇄 패키지 생성**.

원고는 브라우저 안에서만 처리합니다(서버 전송 없음). PDF 엔진(pdf-lib)과 서체는 버튼을 누를 때만 불러옵니다.

## 산출물 (ZIP)
| 파일 | 내용 |
|---|---|
| `print/{제목}_내지_{W}x{H}_도련{b}mm_{N}p.pdf` | 인쇄용 내지. MediaBox=재단+사방 도련, TrimBox/BleedBox 전 쪽 지정, 서체 전체 임베딩, 텍스트 K100(DeviceCMYK) |
| `print/{제목}_표지_{W}x{H}_책등{s}mm.pdf` | 표지 펼침면(뒤표지·책등·앞표지·날개 선택), EAN-13 ISBN 바코드(벡터, K100), 정가 |
| `print/{제목}_표지가이드_작업용.pdf` | 디자이너용 치수 가이드(재단선·접는 선·안전선·패널 폭). 인쇄소에 보내지 않음 |
| `print/인쇄지시서.txt` | 판형·쪽수·도수·책등·제본·확인 필요 항목 |
| `reports/print_preflight.json` | 자동검사 결과, 경고, 사람 승인 게이트 |
| `licenses/*.txt` | 서체 라이선스(SIL OFL 1.1) |
| `manifest/sha256.json` | 전 파일 SHA-256 |

## 조판 규칙
- 구조: 빈 줄로 나뉜 블록 단위. `제N장/부`, `프롤로그·에필로그·들어가며…`, `# 제목` → 장 / `## 제목` → 소제목 / `* * *`, `◇` 등 → 장면 전환. 블록 안 줄바꿈은 행갈이로 보존.
- 문단: 첫 줄 1em 들여쓰기, 양끝맞춤. 어절 단위 줄바꿈을 기본으로, 줄이 성길 때만 한글 음절 사이·URL `/` 뒤에서 나눔. 숫자(ISBN·전화번호)는 나누지 않음. 한 글자짜리 끝줄 금지.
- 금칙: 닫는 문장부호는 줄 첫머리 불가, 여는 부호는 줄 끝 불가.
- 외톨이/과부 줄 방지(문단 첫 줄·마지막 줄이 홀로 남지 않음).
- 표제지 → 차례(장 2개 이상) → 본문(장은 항상 홀수 쪽 시작) → 판권(마지막 짝수 쪽). 쪽수는 지정 배수(기본 4)로 백지 보충.
- 면주: 짝수쪽 책 제목, 홀수쪽 장 제목. 쪽번호: 바깥쪽 아래. 장 시작 쪽에는 면주·쪽번호 생략.
- 판형 프리셋: 140×210, 46판 128×188, 국판 148×210, 신국판 152×225, 크라운판 176×248 (직접 입력 가능).

## 서체
- 본문·제목: 나눔명조 Regular/Bold/ExtraBold (SIL OFL 1.1). 원본 파일 그대로 배포.
- 보조(한자·기호): `ooOS Fallback Serif` — Noto Serif KR(OFL, 예약 서체명 없음)에서 나눔명조에 없는 글자만 추린 서브셋(4.9MB). 원고에 해당 글자가 있을 때만 로드.
- pdf-lib의 CJK 서브셋 임베딩은 글자가 빠지는 문제가 있어 **전체 임베딩**합니다(내지 PDF 약 4–7MB).
- 서체에 없는 글자가 있으면 패키지는 `BLOCKED`.

## 자동검사 (재열기 검증)
원고 글자 보존(원고 비공백 문자 = 배치 문자, 순서 일치) · 서체 지원 · 전 쪽 판면/재단/도련 · 제본 쪽수 배수 · 서체 임베딩 · CMYK 외 색상 0 · 투명도 · 줄 넘침 · 표지 펼침면 치수 · ISBN 체크디지트 + 바코드 디코딩.

## 상태
- `BLOCKED`: 자동검사 실패
- `PRINT_CANDIDATE`: 자동검사 통과. **PRINT_READY는 자동으로 선언하지 않습니다.**
- 사람 승인 게이트 4개(인쇄소 사양 확정 · 교정 최종 승인 · 표지 디자인 승인 · 판권 정보 확인)를 모두 체크해야 화면에 "PRINT-READY 후보"로 표시.

## 알려진 한계 (완료로 표시하지 않음)
- PDF/X-1a/X-4 규격 인증 파일이 아님(OutputIntent·ICC 없음). 인쇄소 요구 시 변환·검증 필요.
- 책등 폭 = ⌈쪽수/2⌉ × 종이 두께(mm/장) + 여유(기본 0.5mm). 인쇄소 확정값으로 재생성 필요.
- 표지 기본 배치는 타이포그래피 시안 수준. 디자인 표지는 앞표지 이미지(JPG/PNG, 300ppi 권장) 업로드 또는 디자이너 작업(가이드 PDF 사용).
- RGB 이미지는 경고만 하고 변환하지 않음.
- 각주·표·그림·캡션 조판은 아직 미지원(텍스트 원고 중심).
- 실제 인쇄소 납품·인쇄 결과 검증은 미수행.

## 개발
```
npm test                                   # 8개 테스트 (조판·바코드·패키지·기존 출간 묶음 회귀)
npm run print:sample -- 원고.txt 출력폴더 "제목" "저자"   # 로컬 샘플 패키지
```
