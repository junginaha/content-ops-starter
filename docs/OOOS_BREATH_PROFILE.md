# 여백형 에세이 (breath) 편집디자인

짧게 끊어 쓴 경어체 산문 — 에세이·자기계발서처럼 **작가가 행을 직접 끊은 원고**를 위한 편집디자인입니다.
『돈의 면접』 일반판 개편(2026-11)에서 확정한 규칙을 ooOS 조판 엔진에 옮긴 것입니다.

## 언제 쓰이나

원고 분석이 아래 조건을 모두 보면 자동 추천합니다(직접 고를 수도 있습니다).

- 행갈이 문단이 많고 한 행이 짧다 (행갈이 문단 40% 이상 · 평균 행 28자 이하)
- 산문 구성이 둘 이상 있다 — 장당 소제목 1개 이상 / 경어체 25% 이상 / 시작하며·마치며 같은 머리말·맺음말
- 과거 서술형 문장이 적다 (소설이 아님)

이전에는 이런 원고가 **시**로 분류돼 한 편씩 새 쪽에 앉혀졌습니다. 소제목이나 경어체가 있으면 시가 아니라 산문입니다.

## 잠그는 것 (작가 승인값)

| 항목 | 값 (140×210 기준) |
|---|---|
| 본문 | 고운바탕 11pt |
| 행간 | 18pt — 판면 밀도·행간 최적화가 바꾸지 않음 |
| 단락 간격 | +4.5pt (행간의 1/4) |
| 행 | 작가가 끊은 그대로. 판면 폭을 넘는 행은 `wrappedSourceLines`로 집계하고 경고 |
| 여백 | 위 24 · 아래 22 · 안 22 · 바깥 18mm (다른 판형은 같은 비율) |

## 디자인

- **부 표제지** — `제1부 …` 또는 `1부 …`. 홀수쪽. 장식 숫자, 부 이름 그대로, 헤어라인, 그 부의 장 목록, (삽화가 3장 이상이면) 작은 삽화 3점. 뒤쪽은 비움.
- **장 도비라** — 홀수쪽 전면. 번호(01, 02 … — 시작하며·마치며 같은 이름 있는 장에는 없음), 장 제목(어절 단위 균형 줄바꿈), 바깥 위쪽의 가는 달(원), 안쪽 아래의 삽화. 원과 삽화는 **겹치지 않게** 배치해 투명 효과 없이 인쇄됩니다. 본문은 다음 짝수쪽부터.
- **소제목** — 위에 9mm 헤어라인, 어절 단위 균형 줄바꿈, 바로 본문.
- **면주·쪽번호** — 아래 바깥 한 줄. 왼쪽 `14  책 제목`, 오른쪽 `장 제목  15`.
- **참고문헌·미주** — 도비라 없이 같은 쪽에서 시작, 작은 글자·좁은 행간·내어쓰기.
- **색** — 먹 1도. 본문 K100, 면주 K62, 라벨 K55, 원 K50, 헤어라인 K45.

## 도비라 삽화

- `/os` → 세부 설정 → 편집디자인이 「여백형 에세이」일 때 **도비라 삽화** 칸이 열립니다.
- 회색(그레이스케일) PNG·JPG만 받습니다. 컬러는 오류로 막습니다(내지 먹 1도).
- 흰 배경을 권장합니다. 투명 배경 PNG는 받되 "투명도 평활화 확인" 경고가 붙습니다.
- 장 도비라에 순서대로 돌아가며 들어갑니다.

## 박(금박·은박) 후가공 규칙

`표지 후가공 → 박`을 고르면 인쇄지시서에 아래가 붙고, 검수 경고에 "박 도면 별도 제작"이 뜹니다.

- 박 자리 아래에는 인쇄를 두지 않는다. 그림 위에 같은 모양의 박을 겹치지 않는다
  (박 공정의 0.5~1mm 핀 오차가 그대로 보인다 — 『돈의 면접』 한정판에서 실제로 생긴 문제).
- 박 도면은 별도 파일(K100 벡터), 박 외곽 1mm 안에 인쇄 요소 없음.
- 0.3mm·8pt 이하의 가는 선·작은 글자는 박에 쓰지 않는다.
- 박 견본으로 위치·번짐 확인 후 본 인쇄.

박 도면 자동 생성은 아직 없습니다.

## 엔진 변경 요약

- `designProfiles.js` — `breath` 프로필, `fixedType`·`lockLeading`·`paragraphGapLines`, 서체 계열(`FONT_FAMILIES`).
- `bookStructure.js` — 부(`part: true`), 이름 있는 장(`named`: 시작하며·참고문헌 추가). 다른 프로필의 조판은 그대로.
- `interiorPdf.js` — 부 표제지, 달 도비라, 헤어라인 소제목, 아래 면주, 참고문헌 조판, K 농도, 삽화·원 그리기, 합자(ligature) 끔.
- `printPackage.js` — 고운바탕 로딩(같은 파일은 한 번만 내려받고 한 번만 임베드), 삽화 검사, 박 규칙.
- `designAnalysis.js` — `breath` 장르 판정.
- 시험: `tests/breath-profile.test.mjs`.
